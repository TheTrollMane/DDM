Rift-Stalker Dragon - Minimal Working Datapack
===============================================

Target:
- Minecraft 1.21.1
- Dragon Survival 2.0.63
- NeoForge

This is a minimal version that registers the species so it appears in the /dragon list
and can be selected. Custom abilities are currently disabled to avoid schema errors.

How to install:
1. Put this entire folder (or the zip) into:
   saves/YourWorldName/datapacks/
2. Make sure pack.mcmeta is at the root of the zip / folder
3. Run /reload (or restart the world)
4. Check with /datapack list
5. Use /dragon riftstalker:rift_stalker  (or the altar)

Next steps (if you want the full abilities later):
- The ability format changed in newer 2.0.x builds.
- We can add simplified abilities once the species is confirmed working.
