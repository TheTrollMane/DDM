Stormfrost Dragon — Dragon Survival 1.21.1 v2.0.63
====================================================

This pack is built against the supplied Dragon Survival 1.21.1 v2.0.63 data/API.

Install:
1. Put this ZIP in your world's datapacks folder.
2. Launch/reload the world with Dragon Survival installed.
3. Use Dragon Survival's species selection to choose Stormfrost Dragon.

Features:
- Separate Lightning Breath and Ice Breath abilities.
- Both breaths use Dragon Survival's channeled breath system and Dragon Survival growth upgrades.
- Lightning Breath levels at growth 0 / 25 / 40 / 60.
- Ice Breath levels at growth 0 / 25 / 40 / 60.
- Cave Dragon mining passive (Cave Claws and Teeth).
- Sea Dragon Water Sight (Sea Eyes).
- Night-in-darkness passive from Dragon Survival.
- Growth-scaled armor passive: 1 / 2 / 3 / 4 armor.
- Ancient Lightning Body passive: when the Dragon Survival self-hit trigger fires, the pack shocks a nearby hostile attacker.
- Broad food tag covering common foods plus Dragon Survival-compatible common food tags.

Notes:
- The supplied Dragon Survival JAR was inspected for v2.0.63.
- The default Dragon Survival body/stages are used so the species uses the existing Dragon Survival model, animation and growth system.
- The Lightning Body command implementation is intentionally conservative: it targets the nearest hostile living entity within 5 blocks when the self-hit trigger fires. This is suitable for melee attackers; a future Java addon can track the exact damage source for projectiles as well.
